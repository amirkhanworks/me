# Amir Khan — Portfolio

A responsive personal portfolio for Amir Khan, showcasing work across technology, business growth, startup ecosystems, research, education, and mentorship.

## Structure

- `index.html` — semantic, single-page portfolio
- `styles.css` — responsive layout and visual system
- `script.js` — mobile navigation and dynamic footer year
- `assets/` — optimized portfolio photography and milestone images (WebP; includes personal University of London photos)

## Run locally

Open `index.html` in a browser. No build step or package manager is required.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/(root)` folder, then save. Once the Pages deployment completes, GitHub will show the published URL in that section.
